# Input File Formats

This document describes the expected format for user-provided input files
required by the synthetic dataset generator.

## :dna: Abundance Profile Files (`data/abundance/*.tsv`)

Abundance profile files define the relative abundances of organisms
in different ecological states (e.g., Healthy, Dysbiosis, Blooming).

### File Location
Place abundance profile files in the `data/abundance/` directory.

### File Naming Convention
The filename pattern is used to extract the ecology state:
```
taxonomy_{prefix}_{diversity_spread}_{ecology_state}.tsv
```

Example: `taxonomy_B1_low_spread_Blooming.tsv` → ecology state: "Blooming"

### File Format

**Structure:**
- **Tab-separated values (TSV)**
- **First column**: Organism/taxon identifiers (row names)
- **Subsequent columns**: Sample names (column headers)
- **Values**: Abundance counts (numeric)

**Example:**
```tsv
sample_001	sample_002	sample_003	sample_004
organism_A	1023070.25	580240.03	754230.34   0
organism_B	0	2580930.38	1580240.34   345345.23
organism_C	580240.03	2080930.43	0  3580240.52
```

**Requirements:**
- Must have a header row with sample names
- First column contains organism/taxon identifiers
- All other columns contain numeric abundance values
- Values can be integers or floating-point numbers
- Zero values are allowed (indicating absence of an organism in a sample)

**Usage:**
The generator randomly selects one sample column from each abundance file
to define organism abundances for synthetic communities.
The selected abundances are normalized to relative abundances (summing to 1.0)
for each simulation.

## :link: MASH Mapping File (`data/mapping/mash.tsv`)

The MASH mapping file provides sequence-based mapping between SRA run accessions
and taxonomic identifiers (SGB IDs) from the ChocoPhlAn reference database.

### File Location
Place the MASH mapping file at `data/mapping/mash.tsv`.

### File Format

**Structure:**
- **Tab-separated values (TSV)**
- **Header row**: Column names (required)
- **Columns** (in order):

| Column | Description | Example |
|--------|-------------|---------|
| `run_accession` | SRA run identifier | `SRR12345678` |
| `organism` | Organism name (ground truth) | `Example organism A` |
| `identity` | Containment score (0-1, higher is better) | `0.95` |
| `shared_hashes` | Shared hash count (format: `count/total`) | `380/1000` |
| `sgb_id` | SGB identifier from reference database | `SGB0001` |
| `taxonomy` | Taxonomic information (semicolon-separated) | `Example organism A (species); Example genus (genus)` |

**Example:**
```tsv
run_accession	organism	identity	shared_hashes	sgb_id	taxonomy
SRR12345678	Example organism A	0.95	380/1000	SGB0001	Example organism A (species); Example genus (genus)
SRR23456789	Example organism B	0.92	350/1000	SGB0002	Example organism B (species)
SRR34567890	Example organism C	0.88	300/1000	SGB0003	Example organism C (species); Example family (family)
```

**Requirements:**
- Must have a header row with exact column names as shown above
- `run_accession` must match the SRA run identifiers used in your FASTQ files
- `identity` should be a numeric value between 0 and 1
- `sgb_id` should be in the format `SGB####` (e.g., `SGB0001`)
- `taxonomy` can contain multiple taxonomic entries separated by semicolons
- Each taxonomic entry follows the format:`Name (rank)`
- Supported ranks: `species`, `genus`, `family`, `order`, `class`, `phylum`,
`kingdom`, or `taxon` (for unrecognized ranks)

**Generation:**
This file is typically generated by running `tools/build_mash_mapping.R`
after performing MASH screening on your organism genomes.

:book: For detailed instructions, see [`docs/MASH_ORGANISM_MAPPING.md`](MASH_ORGANISM_MAPPING.md).

**Usage:**
The generator uses this file to:
- Map run accessions to SGB identifiers for visualization
- Enhance plot labels with taxonomic information
- Generate community profile plots with proper organism identification

**Optional:**
If you don't have MASH mapping results, you can create a minimal version
with just `run_accession` and `organism` columns.
The generator will work without SGB/taxonomy information,
but visualizations will be less detailed.

## :file_folder: Additional Required Files

### Run-Organism Mapping (`data/mapping/run_organism_map.csv`)

A CSV file mapping SRA run accessions to organism names.

**Required columns:**
- `run_accession`: SRA run identifier
- `organism`: Organism name

**Example:**
```csv
run_accession,organism
SRR12345678,Example organism A
SRR23456789,Example organism B
SRR34567890,Example organism C
```

This file is used by `tools/build_mash_mapping.R`
to generate the MASH mapping file.

## :bulb: Tips for Creating Your Own Files

1. **Abundance Profiles:**
   - Use your own metagenomic/metatranscriptomic abundance data
   - Ensure organism identifiers match those in your `run_organism_map.csv`
   - Include multiple samples per ecology state for diversity in synthetic communities

2. **MASH Mapping:**
   - Follow the workflow in [`docs/MASH_ORGANISM_MAPPING.md`](MASH_ORGANISM_MAPPING.md)
   - Use the latest ChocoPhlAn reference database release
   - Aim for identity scores ≥ 0.90 for reliable mappings

3. **Validation:**
   - Check that all run accessions in your mapping files match your FASTQ file names
   - Verify that abundance profile organism identifiers are consistent
   across files
   - Ensure numeric values are properly formatted (no text in numeric columns)
